# qbittorrent-xana-patches

Tweaked qbittorrent for gigantic 500k torrent instances 

Maintained as patches by Stacked Git (sgt). Some may be upstreamed

* **Qb: Serialize torrents as array**
* **Qb: Metrics**
* **lt: Fix large exit times**
* binary serialization with capn proto
* exponential backoff for webseed
